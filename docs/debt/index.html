Demo environment · recorded runs

Reads a company's dataroom. Produces a credit snapshot and a debt structure. Then answers for it.

The pipeline behind this is built around one rule: the model never computes a number that code can compute. Spreadsheets are parsed deterministically; only the documents that genuinely need language or vision go to a model; one reasoning call chooses the structure; then code re-checks the serviceability arithmetic and prints warnings when the answer does not hold up.

You are in the demo environment — three recorded runs on fictional companies, with the chat transcripts they produced. Nothing to set up. To run it on a real case, add your own Anthropic key and upload a dataroom; both stay in this tab.

How your key and files are handled

  • This page is static. There is no server of ours in the path — the key goes from this tab straight to api.anthropic.com.
  • Stored in sessionStorage only. It dies with the tab. Never localStorage, never a cookie.
  • Sent in a request header, never in a URL, so it cannot land in a log or your browser history.
  • Files are read in the browser. They are sent to Anthropic as part of your request and nowhere else.
  • Provider errors are run through a redactor before they are shown, so a bad key never appears on screen.
