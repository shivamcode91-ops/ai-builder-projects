# others/ — supporting material (not deliverables)

Everything a reviewer needs is at the repo root; this folder holds the supporting
evidence and process artifacts.

- `phase1_experiments/` — how the pipeline was validated **before spending the Prism
  key budget**: full live runs of all 3 companies plus a chat transcript through a
  free stand-in gateway (`groq/`). This is the cost-management story.
- `phase2_runbook.md` — the exact commands, budget math, and packaging steps used to
  produce the final `final_outputs/` with the Prism candidate key.
