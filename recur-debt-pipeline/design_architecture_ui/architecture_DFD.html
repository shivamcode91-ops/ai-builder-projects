AICA Debt-Structuring Pipeline — swimlane data-flow

One command per company: Dataroom + AICA report → credit snapshot → recommended debt structure → grounded multi-turn chat. Measured per Prism run (Haiku 4.5 + Sonnet 4.6): ~9k input / ~6k output tokens ≈ $0.07–0.10, 90–120 s wall clock; chat ≈ 5–7k input / turn. Streamed responses (CloudFront-safe); disk cache makes unchanged re-runs free.

Reading the diagram: follow the numbers ① → ⑫. Step A is the run: the underwriter points at a company folder; Excel goes through deterministic parsers (never into a prompt), the 5 small documents go through Haiku extraction, everything merges into a computed snapshot whose ratios and data-quality flags are code-derived; one Sonnet call turns the snapshot into a structure; code re-checks the structure's own arithmetic before anything reaches the screen. Step B is the chat: follow-ups are answered from the compact run output (~6 KB), not the dataroom, so each turn costs ~5–7k input tokens and stays on the same company. Only the two purple boxes in Step A and one purple box per chat turn ever spend tokens — everything else is exact and free.
